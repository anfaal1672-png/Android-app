# AI一括ペースト（Android）

AIに決まった形式（`【項目名】` 区切り）で出力させ、その回答をまとめてコピーし、他アプリの複数の入力欄に項目ごとに一括で貼り付けるアプリです。

## 使い方
1. アプリの「指示文をコピー」でAIへの指示文をコピーし、末尾に依頼内容を書いてAIに送る
2. AIの回答をまとめてコピーし、アプリを開く（自動で読み込み）か「クリップボードから読み込む」
3. 設定 → ユーザー補助 →「AI一括ペースト」をオン
4. 貼り付け先のアプリで丸い「貼」ボタンを押す → 入力欄に番号が付く → ◀▶で割り当てを調整 →「一括貼り付け」

## ビルド
```
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```
